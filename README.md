# Bassant Hany Fahmy — Portfolio

Professional portfolio for Bassant Hany Fahmy, a technical and electromechanical specialist in Giza, Egypt. The page presents her railway locomotive maintenance training, automatic pneumatic control systems course, education, technical competencies, and applied electrical and mechanical projects.

The site is built with static HTML, CSS and JavaScript. Profile photographs and the railway background are stored in `assets/`; project images are stored in `assets/projects/`. The `favicon.svg` file contains the BH monogram.

## Deploy to Vercel

Import the repository into Vercel using the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` contains these settings; no build step or dependencies are required.
